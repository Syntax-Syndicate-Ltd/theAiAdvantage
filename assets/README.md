# Presentation Logo Assets Guide

Welcome! This folder holds the logo images for the slide deck. 

The HTML code uses a **smart fallback system**. If you haven't placed an image in this directory yet, the slide will automatically display a clean vector icon on a teal background. The moment you drop the corresponding image file in here, it will automatically transition to display your logo in high resolution!

## Logo Files List

To replace the icons with official logos, save your image files in this folder (`assets/`) using the exact filenames listed below.

For the best visual quality:
- Use square or circular images (1:1 aspect ratio).
- Use **transparent PNG** formats if possible.
